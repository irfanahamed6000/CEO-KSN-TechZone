Irfan Ahamed Portfolio (with contact form saved to a text file)

HOW TO RUN
1. Install Python 3 from python.org (tick "Add Python to PATH").
2. Open a terminal / Command Prompt in this folder.
3. Install Flask (one time):   pip install -r requirements.txt
4. Start the site:             python app.py
5. Open http://127.0.0.1:5000 in your browser.

WHERE THE FORM DATA GOES
Every message from the contact form is added to messages.txt
(in this same folder). Open it with Notepad any time. The file is
created automatically after the first message.

NOTES
- Keep the terminal open while the site is running (Ctrl+C to stop).
- Opening index.html by double-click will show the site, but the
  contact form only saves messages when you run it with python app.py.
- To put it online, host it on a Python host (for example PythonAnywhere
  or Render). Static hosts such as Netlify cannot run app.py.
- Change the email text (hello@example.com) in index.html.

ADDING YOUR PHOTO AND PROJECT LOGOS
Copy your images into the "images" folder using the names listed in
images/PUT-YOUR-IMAGES-HERE.txt (for example irfan.jpg, mj-traders.png),
then refresh the page.
